# 研发协同管理：产品路线图

## 产品目标

让项目负责人在一个入口回答四个问题：每个项目为什么做、依据在哪里、现在做到哪一步、下一步该由谁处理。项目事实来自本地工作区、GitLab/GitHub、项目材料、测试/CI、Agent 事件和经授权的沟通记录；任何自动结论都能回到来源、时间和适用版本。

首批真实场景是低电压、设备缺陷处置、HY Claw 和 HyClaw 本地部署。产品以日常查看和决策为中心，不以采集事件数量作为成功指标。

## 产品原则

- **先事实，后推断**：区分已验证事实、材料中的计划、模型建议和待确认事项。资料过期或接口失败时明确显示，不用 0 或“正常”代替未知。
- **项目是主语**：一个业务项目可关联多个仓库、资料目录、群聊、人员与执行节点；项目名和关联关系可以维护。
- **少量入口，逐层深入**：先看跨项目总览，再看项目进展和证据，最后进入原始材料、提交、会话和任务。
- **本地与权限边界清晰**：原始项目文件不搬迁；微信仅采授权会话。密钥不进仓库、页面或日志。对外发送要有目的地白名单、去重与审计。
- **可恢复运营**：采集、索引、模型分析和通知各自有健康状态、失败原因和重试路径；重建容器不丢状态。

## 阶段与验收

| 阶段 | 用户可见结果 | 验收标准 |
| --- | --- | --- |
| P0 · 项目组合首页 | 打开即看到所有项目的背景、阶段、下一步、问题、资料、代码与沟通概况 | 四个真实项目完整出现；可从卡片进入详情及认知；部分来源失败仍可看其他项目；日期与未知状态如实展示；窄屏可操作 |
| P1 · 可信项目档案 | 背景、目标、交付物、当前版本、负责人、关键决定和资料入口汇成一页 | 每条关键结论带来源和观察时间；同名/多版本资料可辨；过期来源提示；可修正项目绑定而不改原始文件 |
| P2 · 工作台与检索 | 跨项目搜索问题、决定、材料、代码和任务，并能查看变更 | 搜索结果标明项目/来源/时间；能按项目和来源过滤；同一事实不重复刷屏；任务状态只在证据足够时推进 |
| P3 · 微信项目助手 | 用户从自己的授权微信会话发项目指令，收到带证据的答复 | 仅白名单会话与发送人可触发；命令收发在真实会话闭环；发送失败可追踪/重试且不重复；不向正式项目群发测试消息 |
| P4 · 通知与自动简报 | 重大变化及时提示，按需生成项目简报；Hermes 继续负责外部 AI 情报 | 通知可订阅/静音、可回溯来源；同一事件不重复推送；简报能区分新变化与历史事实 |
| P5 · 可交付产品 | 多用户权限、安装升级、备份恢复与运营监控 | 新机器能按文档安装；权限按人/项目隔离；备份恢复演练通过；升级和回滚可验证；核心流程有持续集成与真实环境验收 |

## 实施顺序

1. 先完成 P0，并在本机运行的四个项目上验证。随后把组合首页的数据聚合移到服务端，避免项目数增多时产生大量浏览器请求。
2. 完成 P1 的项目身份、来源日期和人工校正，再推进 P2 检索与任务。没有这些基础，问答会把历史计划当成当前进展。
3. M7 微信读取与指令链路按独立集成推进；先验证同账号真实收发，再接入 P3。M8 的主动通知在 P3 稳定后实施。
4. 每阶段在真实项目上做一次可观察验收，记录失败和数据盲区；不以 CI 绿灯替代实际使用验证。

## 当前边界

截至 2026-09-28，Central、Sentinel 和项目认知在本机运行；经授权的微信群增量读取在独立的 M7 草稿分支验证，微信机器人回复与用户本人账号发送链路仍需独立验证。本路线图不表示这些功能已经全部发布到 `cao`，并随实现与真实验收更新。

本轮已完成 P0 的首个可用切片：默认跨项目首页、本地四项目真实数据、项目搜索、详情/资料入口、来源缺失与资料日期提示，以及窄屏布局。2026-09-28 本机读取到 4 个项目、12 份已识别材料和 7 个关联仓库；其中 2 个项目的资料日期超过 14 天，1 个项目资料时间未知。这些数字是当时的本机快照，后续以页面实时数据为准。

P1 的首个切片已把项目背景、阶段、下一步、负责人、事实摘录和最近材料放在同一档案页，并分别标明资料日期、本地采集时间及可用的原始链接/材料路径。HY Claw 的项目认知与自动资料汇总阶段不一致，页面会并列提示；低电压和缺陷项目尚缺逐条支撑阶段判断的来源，因此明确标为“自动汇总，尚未关联逐条依据”。后续仍需补齐逐条来源关联和人工校正机制，P1 尚未全部验收。

第二个切片把自动阶段判断、资料中的下一步和关键决定回连到原始材料路径及日期。阶段依据明确标成启发式推断，旧待办显示距今时间和“是否仍待办需确认”；资料路径不会被当作功能验收证明。可编辑的人工校正、当前版本/交付物登记仍待实现，P1 不因此宣称全部完成。
